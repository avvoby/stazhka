# Весенняя неделя карьеры ВШБ — Документация

## Быстрый старт

1. Заполнить Google Таблицу контентом (см. структуру ниже)
2. Включить модуль: `CAREER_WEEK_ENABLED=true` в `.env` на сервере
3. Перезапустить бота: `docker compose up -d --build bot`
4. Проверить: `/cwadmin` → **Обновить контент**

### Лист `roast_slots`

| `id` | `type` | `date` | `time` | `direction` | `capacity` |
|------|--------|--------|--------|-------------|-----------|

Пример строк:
```
slot_001 | resume    | 14 апреля | 11:00 | Консалтинг | 5
slot_002 | interview | 15 апреля | 14:00 | Бигтех     | 4
```

Правила:
- `id` — уникальный идентификатор слота (строка без пробелов)
- `type` — только `resume` или `interview`
- `capacity` — максимальное число участников на слот
- При обновлении контента (`/cwadmin → Обновить контент`) capacity обновляется в БД, счётчик занятых мест не сбрасывается

## Как обновить контент

`/cwadmin` → **Обновить контент**

Бот прочитает все листы таблицы и обновит кэш Redis.
Пользователи увидят новые данные немедленно (без перезапуска бота).

Кэш живёт 24 часа — если бот долго работает без обновления, данные могут устареть.
Рекомендуется обновлять после каждого редактирования таблицы.

## Как сделать рассылку

`/cwadmin` → **Рассылка**

1. Выбрать аудиторию:
   - Всем зарегистрированным
   - По направлению обучения
   - По курсу
   - По списку Telegram ID
2. Написать текст (поддерживается HTML: `<b>`, `<i>`, `<a href>`)
3. Добавить кнопку (опционально): текст кнопки → URL
4. Прикрепить файл/фото (опционально)
5. Подтвердить отправку

Рассылка идёт поочерёдно по всем получателям с задержкой 50 мс между сообщениями.
В конце бот показывает статистику: отправлено / ошибок.

## Управление администраторами

**Добавить через бота:** `/cwadmin` → **Управление админами** → **Добавить**
→ ввести Telegram ID (числом)

**Добавить через таблицу:** добавить строку в лист `admins`

→ ввести Telegram ID (числом)

Суперадмин (ID 5645685337) удалить нельзя — доступ сохраняется всегда.

## Регистрация участника (5 шагов)

1. Направление обучения (кнопки: Экономика, Менеджмент, Юриспруденция, ...)
2. Уровень образования (Бакалавриат / Магистратура)
3. Программа обучения (из листа `programs`, фильтр по уровню; или ввод вручную)
4. Курс (1–4 / Магистратура 1–2 / Аспирантура)
5. Навыки (мультиселект из листа `skills`; можно добавить свой)

По завершении — уникальный 5-символьный код участника (буквы + цифры).
Код используется для получения баллов на мероприятии.

## Запись на прожарку

Пользователь выбирает:
1. Тип (прожарка резюме / прожарка собеседования)
2. Направление (из доступных слотов)
3. Конкретный слот (дата + время, показывается занятость)
4. Резюме (файл PDF/фото / ссылка / пропустить)

Бронирование атомарное — если слот заполнен в момент подтверждения,
пользователь получает уведомление и может выбрать другой.

Один пользователь может записаться на несколько прожарок разного типа.
